개인정보처리방침

운영 검토용 초안
작성일: 2026년 11월 10일. 시행일은 공개 전 확정합니다. 운영 주체, 개인정보 문의 창구, 최종 호스팅의 처리 관계와 보유기간을 확인한 뒤 법률 검토를 거쳐 확정해야 합니다.

KANG MIN HYUK 홈페이지의 개인정보 처리 방식을 안내합니다. 본 초안은 소개 콘텐츠와 외부 공식 채널 링크를 제공하는 현재 홈페이지 구성을 기준으로 작성했습니다.

1. 운영 주체와 문의 창구

운영 주체
확인 필요: 실제 개인정보처리자 명칭 및 해당 시 사업자 정보
보호 담당자
확인 필요: 성명 또는 담당 부서
연락처
확인 필요: 열람·정정·삭제·처리정지 요청을 받을 이메일 또는 전화번호

2. 처리 목적과 항목

현재 홈페이지에는 회원가입, 로그인, 댓글, 결제, 뉴스레터 구독, 문의 입력 기능이 없습니다. 운영자가 이러한 기능으로 이름·이메일·전화번호를 입력받는 경로도 두지 않았습니다. 자체 방문 분석 스크립트, 광고 추적 도구, 외부 동영상·SNS 임베드도 사용하지 않습니다.

웹사이트 제공 및 보안 과정에서 호스팅 제공자가 IP 주소와 접속 관련 정보를 처리할 수 있습니다. GitHub Pages를 최종 호스팅으로 사용하는 경우, GitHub는 보안 목적으로 방문자의 IP 주소를 기록·보관한다고 안내합니다. 검토용 Sites 환경의 인증 및 접속정보 처리는 해당 서비스의 정책과 실제 운영 구성을 별도로 확인해야 합니다.

3. 처리 근거 및 보유기간

사이트 자체 입력 기능으로 수집·보유하는 개인정보는 현재 없습니다. 호스팅·보안 접속정보의 처리 항목, 적법한 처리 근거, 보유기간, 운영자의 접근 가능 여부는 최종 호스팅 선택 후 확인하여 명시합니다. 확인 전에는 임의의 보유기간을 정하지 않습니다.

4. 제3자 제공·위탁·국외 이전

현재 자체 입력 기능을 통해 수집한 개인정보를 제3자에게 제공하는 기능은 없습니다. 호스팅 및 인증 서비스의 이용이 개인정보 처리위탁이나 국외 이전에 해당하는지는 서비스 계약과 실제 처리 구조에 따라 확인해야 합니다.

확정 시 수탁자 및 위탁 업무, 이전 국가, 이전받는 자와 연락처, 항목, 목적, 시기·방법, 보유기간, 법적 근거 및 거부 방법 등 해당 고지 사항을 반영합니다.

5. 파기 절차와 방법

현재 운영자가 자체 입력 기능으로 보유하는 개인정보는 없습니다. 향후 보유 정보가 생기면 목적 달성 또는 보유기간 종료 시 법령상 보존 의무가 있는 경우를 제외하고 지체 없이 파기하며, 전자 파일은 복구하기 어려운 방법으로 삭제하고 종이 문서는 분쇄 등의 방법으로 처리하도록 운영 절차를 확정합니다. 호스팅 제공자의 접속정보 삭제 절차는 해당 제공자의 정책과 계약을 확인합니다.

6. 정보주체와 법정대리인의 권리

정보주체와 적법한 법정대리인은 적용 법령에 따라 개인정보 열람, 정정·삭제, 처리정지 등을 요청할 수 있습니다. 실제 요청 창구와 본인·대리인 확인 절차는 공개 전 확정하여 안내합니다. 외부 서비스가 독립적으로 처리하는 정보는 해당 서비스의 개인정보 권리 행사 창구를 이용할 수 있습니다.

7. 쿠키 및 외부 링크

홈페이지 자체 코드에는 쿠키·로컬 저장소를 이용한 추적 기능이 없습니다. 호스팅·인증 서비스가 사용하는 쿠키 등은 최종 환경에서 확인하여 고지합니다. 브라우저 설정에서 쿠키를 제한하거나 삭제할 수 있으나, 필요한 인증 기능이 제한될 수 있습니다.

YouTube와 Instagram은 링크를 선택했을 때 새 창으로 이동합니다. 이동한 서비스에는 각 서비스의 개인정보처리방침이 적용됩니다.

8. 안전성 확보 조치와 변경

공개 전 HTTPS 적용, 관리 계정의 접근 권한 제한과 인증 설정, 개인정보 문의 처리 절차 등 실제 적용한 조치를 확인하여 명시합니다. 기능이나 이용 서비스가 바뀌면 본 방침을 검토하고, 확정된 시행일과 변경 내용을 홈페이지에 안내합니다.
