운영자 명칭, 개인정보 문의 이메일 및 시행일: 출시 전 확정
현재 개발 중인 앱 구성을 기준으로 한 안내입니다. 최종 배포 앱의 데이터 처리와 외부 구성요소를 확인하고 법률 검토를 거쳐 정식 방침을 확정합니다.

DrumUp은 사용자가 선택한 음악을 듣고 반복하며 드럼 연습을 할 수 있도록 준비 중인 Android 앱입니다. 이 문서는 DrumUp 앱의 개인정보 처리에 관한 사전 안내이며, 공식 홈페이지 방문에 관한 사항은 홈페이지 개인정보처리방침에서 안내합니다.

2. 처리하는 정보와 목적

현재 개발 구성은 선택한 음원과 연습 설정을 기기 안에서 처리하도록 구현되어 있습니다. 회원가입·서버 계정·서버 동기화, 광고·결제 및 자체 방문 분석 기능은 현재 구현되어 있지 않습니다. 정식 출시 시 기능이 달라지면 실제 처리 내용에 맞춰 방침을 갱신합니다.

정보·기능현재 개발 구성에서의 처리 목적과 위치
사용자가 선택한 음원과 파일 표시명사용자가 Android 파일 선택 화면에서 고른 파일을 앱 내부 저장공간으로 복사해 가져오기, 음원 처리 및 재생에 사용합니다. 사용자가 선택한 외부 원본 파일은 원래 위치에 남습니다.
음원 처리 결과와 임시 파일분리·재생을 위한 오디오 파일을 앱 내부에 생성합니다. 기기 성능과 음원 길이에 따라 처리 시간과 저장공간 사용량이 달라집니다.
곡별 연습 설정BPM, 클릭 시작점, 재생 위치·속도, 듣기 모드·음량, 반복 구간 및 저장한 연습 이름 등을 연습 재개와 보관함 기능에 사용합니다.
음성 카운트설치된 Android 음성 읽기 엔진에 고정 숫자 단어를 전달해 카운트 음성을 만듭니다. 선택한 음원·파일명·BPM·연습 기록은 해당 엔진에 전달하지 않는 구성입니다.
기기 내 진단 로그오류나 재생 상태를 확인하는 Android 진단 로그에 파일명·경로 등 일부 정보가 포함될 수 있습니다. 현재 자체 오류 수집 서버로 보내는 기능은 확인되지 않았습니다.

3. 외부 전송과 외부 서비스

현재 앱은 직접 인터넷 접속 권한을 제거하고, 오디오 처리용 구성요소의 자동 정보 수집을 차단하도록 구성하고 있습니다. 최종 출시 앱과 포함된 구성요소의 실제 처리 동작을 검증한 뒤 외부 전송, 처리위탁, 제3자 제공 및 국외 이전의 해당 여부를 확정합니다.

Android 음성 읽기 엔진과 파일 선택기에 연결된 클라우드 저장소는 별도 앱 또는 서비스일 수 있습니다. 이들의 자체 통신과 데이터 처리에는 각 제공자의 정책이 적용될 수 있습니다. 이 안내는 기기 운영체제나 다른 서비스의 모든 통신이 없다는 의미가 아닙니다.

현재 앱에는 자체 클라우드 백업 기능이 없고, 앱의 Android 자동 백업도 제외하는 구성입니다. 사용자가 별도 도구로 내보내거나 보관한 파일은 해당 도구와 저장 위치에서 관리해야 합니다.

4. 보관기간과 삭제 방법

현재 개발 구성에서는 음원과 연습 설정을 기능 이용에 필요한 동안 기기에 보관합니다. 보관함 항목을 삭제할 수 있으나, 같은 음원을 현재 곡 또는 다른 연습 항목이 참조하면 관련 음원 파일이 즉시 지워지지 않을 수 있습니다. 다른 곡을 선택하고 참조하는 보관함 항목을 정리하거나, Android 설정에서 DrumUp의 앱 저장공간을 삭제하거나 앱을 제거해 앱 내부 데이터를 지울 수 있습니다.

음성 합성용 임시 파일은 처리 완료·취소·실패 시 정리하는 구성입니다. 강제 종료 등으로 남은 임시 캐시는 Android의 앱 캐시 또는 저장공간 삭제로 정리할 수 있습니다. 앱 내부 데이터 삭제는 사용자가 외부에서 선택한 원본 음원을 삭제하는 작업과는 별개입니다.

향후 운영자가 별도로 수집·보관하는 개인정보가 생기면 실제 처리 근거, 보유기간, 파기 절차와 방법, 법령상 보존 대상 등을 정식 방침에 명시합니다.

5. 기기 권한

현재 개발 구성은 재생 중 백그라운드 서비스와 화면·기기 절전 관련 Android 기능을 사용합니다. 마이크·카메라·연락처·위치·광범위 저장소 읽기 권한을 요청하는 구성은 아닙니다. 음원은 사용자가 시스템 파일 선택 화면에서 직접 고릅니다. 최종 출시 앱의 권한과 이용 목적을 다시 확인하여 안내합니다.

6. 제3자 제공·위탁·국외 이전

현재 자체 계정이나 수집 서버를 통해 개인정보를 제공하는 기능은 구현되어 있지 않습니다. 다만 포함된 구성요소, 외부 서비스 및 정식 운영 구조를 기준으로 제공·위탁·국외 이전 관계를 최종 확인해야 합니다. 해당하는 처리가 있으면 제공받는 자·수탁자·이전받는 자, 목적, 항목, 국가, 시기·방법, 보유기간, 법적 근거 및 거부 방법 등 적용되는 사항을 정식 방침에 반영합니다.

7. 정보주체와 법정대리인의 권리

정보주체와 적법한 법정대리인은 적용 법령에 따라 개인정보 열람, 정정·삭제, 처리정지 등을 요청할 수 있습니다. 기기에 저장된 정보는 앱 기능과 Android 앱 저장공간 설정을 통해 관리할 수 있습니다. 운영자가 처리하는 정보에 대한 권리 행사 방법과 본인·대리인 확인 절차는 공개 문의 창구와 함께 출시 전 확정합니다.

8. 안전성 확보와 변경 안내

선택한 음원과 연습 정보를 앱 내부 저장공간에서 관리하고 불필요한 권한과 외부 전송 경로를 줄이는 구성을 적용하고 있습니다. 최종 운영 구조에 따라 접근 권한 관리, 보관·파기 및 문의 처리 절차 등 실제 안전조치를 확인해 정식 방침에 반영합니다.

문의 창구 확정, 기능 추가 또는 데이터 처리 변경이 있을 때에는 이 페이지를 갱신하고, 정식 시행일과 주요 변경 내용을 안내합니다. 사전 안내본은 최종 출시 앱과 스토어의 개인정보 표시를 확정했다는 의미가 아닙니다.
